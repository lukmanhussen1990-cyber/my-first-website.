Install on your phone

  1. Download the .mcpack with the button above. Chrome may warn about the file type — choose Download anyway.
  2. Tap the file in your notification shade or Downloads folder. Minecraft opens and shows Import started, then Successfully imported.
  3. Create or edit a world. In world settings turn on Activate Cheats — commands will not run without it.
  4. Behavior Packs → Beautiful Base → Activate. If it asks about experimental features, you can say no; this pack does not need them.
  5. Enter the world, stand on flat ground facing the way you want the front door to face, and open the chat.
  6. Run /function beautiful_base. The house builds in front of you instantly.
  7. Changed your mind? Stand on the same spot and run /function clear_base to erase it.

Heads up: the build is placed a few blocks north of where you stand and always faces the same way — Minecraft functions ignore which direction you are looking. Flat ground gives the best result.

Every block you see in the preview is exactly what the add-on places. Made for Bedrock Edition on Android, iOS, Windows and console.
