# Character prompts (GPT Image): adam-silent

Make these in ChatGPT and save them in **`grace-reels/episodes/adam-silent/assets/chars/`** with the EXACT file names below.
Then type **DONE**.

## How to make them

1. **Order matters.** Make the 4 face references first: **#1 Adam, #6 Eve, #14 Jesus, #20 young man**. Every later prompt for that character attaches its face reference, so the person looks the same in every picture.
2. **Attach** the files listed under "Attach" for each prompt. The `style_ref_*.png` files are in `episodes/adam-silent/style_refs/`.
3. **Eyes-closed versions (the "b" items)** are edits, not new pictures. In the same chat, open the image you just made, select only the eyes with the edit brush if you have it, and paste the edit prompt. Small shifts are OK: I line them up in Phase 3.
4. **Background:** ask for transparent. If ChatGPT gives a background anyway, use the magenta fallback. I remove magenta cleanly.
5. **MUST** = I need it for the reel. **NICE** = makes it better; I have a code fallback if it's missing.
6. Small mistakes (a stray leaf, slight color shift) are fine: I fix them in Phase 3. Please redo any image with extra fingers, a halo on Jesus, or a garment that doesn't cover from shoulders to knees.
