# Wedding reel - image prompts ("MOM! I'M DONE!")

Reel: 1080x1920, 30 fps, 61.1 s, 36 shots. Voiceover is done (`audio/voiceover.mp3`, Nassim, same voice and settings as the last reels).

## How to use

1. Open ONE new ChatGPT chat. Paste the **character sheet** prompt first.
2. Then paste the shot prompts one by one, in order, in the same chat (so the characters stay the same).
3. Save each image as `shot_01.png`, `shot_02.png` ... (or just send them to me in order).
4. For the **6 KEY shots** (marked with a star), also make a Kling clip from that image (image-to-video, 9:16, 5 s) with the short Kling prompt. Save as `shot_05.mp4` etc. I only use the best 1-2 seconds of each clip, so a 5 s clip is plenty. If you skip a clip, I animate the image instead.
5. Send me the images and clips. I build `final.mp4` after that (zooms, shake, captions, effects, sound).

Tips: if a face drifts, reply "Same character as the character sheet, match the face exactly." If text or letters appear in an image, reply "Same image with no text." (Only shot 10 has words: "Reserved: Mom" and shot 36 has words: "Just Married".) Captions, stink lines, sweat drops, tears, shake and flashes are added by me in the edit, so they are not needed in the images (except where a prompt asks for tears).
