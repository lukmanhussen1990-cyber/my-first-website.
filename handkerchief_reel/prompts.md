# Handkerchief reel - image prompts ("You're homeless")

Reel: 1080x1920, 30 fps, 73.7 s, 41 shots (about 1.8 s each, like the last reels). Voice: your own voiceover (`audio/voiceover.mp3`), with a few longer pauses for timing.

## How to use

1. Open ONE new ChatGPT chat. Paste **character sheet 1** first, then **character sheet 2**.
2. Then paste the shot prompts one by one, in order, in the same chat (so the faces stay the same).
3. Save each image as `shot_01.png`, `shot_02.png` ... (or just send them to me in order).
4. For the **6 KEY shots** (marked with a star: 02, 04, 07, 18, 30, 35), also make a Kling clip from that image (image-to-video, 9:16, 5 s) with the short Kling prompt. Save it as `shot_04.mp4` etc. I only use the best 1-3 seconds of each clip, so 5 s is plenty. No clip? No problem - I use the image.
5. Send me the images and clips. I build `final.mp4` right after that (zooms, shake, captions, date labels, effects, sound).

Tips: if a face changes, reply "Same face as the character sheet, match it exactly." If text or letters appear in an image, reply "Same image with no text." Captions, date labels (DAY 1, MONTH 3, YEAR 1, 50 YEARS LATER), the "0.1 SEC" display, stink lines, sweat drops, hearts and sparkles are added by me in the edit, so they are not needed in the images.

Rules kept in every prompt: funny and sweet, never gross; everyone stays dressed; the bush always hides him (only his head and shoulders show above it).
