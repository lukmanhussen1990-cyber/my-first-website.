# Bear reel - image prompts ("You just pooped in the forest")

Reel: 1080x1920, 30 fps, 44.4 s, 29 shots. Voiceover is done (`audio/voiceover.mp3`, Nassim, same voice and settings as the last reels).

## How to use

1. Open ONE new ChatGPT chat. Paste the **character sheet** prompt first.
2. Then paste the shot prompts one by one, in order, in the same chat (so the characters stay the same).
3. Save each image as `shot_01.png`, `shot_02.png` ... (or just send them to me in order).
4. For the **6 KEY shots** (marked with a star), also make a Kling clip from that image (image-to-video, 9:16, 5 s) with the short Kling prompt. Save as `shot_06.mp4` etc. I only use the best 1-2 seconds of each clip, so a 5 s clip is plenty.
5. Send me the images and clips. I build `final.mp4` after that (zooms, shake, captions, effects, sound).

Tips: if a face drifts, reply "Same YOU as the character sheet, match the face exactly." If text or letters appear in an image, reply "Same image with no text." Captions, stink lines, fog, sweat drops, tears and the "x7" sign are added by me in the edit, so they are not needed in the images (except where a prompt asks for tears).
