# SCP-096 for Minecraft Bedrock (mobile) — add-on guide

Built for **Minecraft Bedrock 1.21.0** (your screenshot: *beta 1.21.0.26*, Android). One file to import:
**`SCP-096.mcaddon`** (Behavior Pack + Resource Pack, linked by `manifest.json` dependencies, brand-new UUIDs).

* **No experimental toggles needed.** (Beta APIs, Holiday Creator Features etc. stay OFF.)
* Entity id: `scp:scp096`, name **SCP-096**, spawn egg **SCP-096 Spawn Egg** (pale white with dark grey spots).
* Honest status: every file was checked against Mojang's own 1.21.0 sample files, validators, and simulations, and the model and poses were rendered and inspected — but **nobody could run Minecraft here**. The first real test is yours; section 4 tells you exactly what to look at and what to send me if something is off.

## 0. Quick start (phone)

1. Download `SCP-096.mcaddon` and tap it (Files / Downloads) → choose **Minecraft** → wait for "Successfully imported" (you get *SCP-096 Behavior Pack* and *SCP-096 Resource Pack*).
2. Create or edit a world (pencil icon) → **Behavior Packs → SCP-096 Behavior Pack → Activate**. The Resource Pack comes with it automatically (check it is listed under *Resource Packs → Active*; if not, activate it).
3. Game mode **Survival**, difficulty **Easy / Normal / Hard** (not Peaceful). Enter the world.
4. Get the egg: open the inventory (Creative inventory works even in a Survival world if cheats are on), **Nature tab, scroll to the end**, or type **SCP** or **096** in the search box. Place the egg on the ground. (Or `/summon scp:scp096 ~ ~ ~`.)
5. It sits and sobs. Switch to Survival, walk up, and **look at its face** — see section 4.

Remove it any time: `/kill @e[type=scp:scp096]` (normal hits do almost nothing: 500 HP and damage ×0.1).

## 0.1 Make the .mcaddon yourself on the phone (only if you want to)

1. Copy the two folders `SCP096_BP` and `SCP096_RP` (the folders themselves, with everything inside) next to each other on your phone.
2. In a file manager that can zip (ZArchiver, Files by Google, Solid Explorer…): select **both folders** → *Compress / Archive* → format **ZIP**, no password.
3. Rename the result from `something.zip` to **`SCP-096.mcaddon`** (turn on "show file extensions" first).
4. The two folders must be directly at the top level of the zip — not inside another folder.
5. Tap the file to import. (iOS: Share → *Copy to Minecraft*.)
The binary files (texture, sounds, icons) are in the repo folders; they are regenerated by `tools/make_texture.py` and `tools/make_sounds.py`.
