# my-first-website.

## Voxelcraft — `minecraft.html`

A Minecraft-style voxel game in a single HTML file. No libraries, no build step,
no assets: open the file in a browser and play. Everything — terrain, textures,
meshing, physics, sound — is generated by the ~2000 lines of JavaScript inside it.

### Play

Open `minecraft.html` in any browser with WebGL, or serve the folder and visit it:

```
npx serve .        # then open http://localhost:3000/minecraft.html
```

Click the world to capture the mouse. Your edits, position and seed are saved to
`localStorage`, so closing the tab and coming back drops you where you left off.

### Controls

| Key | Action |
| --- | --- |
| `W` `A` `S` `D` | Move |
| Mouse | Look |
| `Space` | Jump · swim up · fly up (double-tap to toggle flying) |
| `Shift` | Sneak · fly down |
| `Ctrl` | Sprint |
| Left click | Break block (hold to keep breaking) |
| Right click | Place block |
| Middle click | Pick the block you're looking at |
| `1`–`9`, mouse wheel | Select hotbar slot |
| `E` | Block palette — all 23 blocks |
| `F` | Toggle flying |
| `T` | Advance time of day |
| `R` | Respawn at the surface |
| `Esc` | Pause menu, render distance and FOV |

### What's in it

- **Terrain** — value noise fbm with a stretched base and a separate mountain
  mask, so a seed produces oceans, beaches, plains, forests, deserts, snow-capped
  peaks up to y=86, 3D-noise caves, and ore veins that get rarer with depth.
- **Textures** — a 128×128 atlas painted pixel by pixel onto a 2D canvas at
  startup: grass, bark rings, staggered brickwork, ore speckles, woven wool.
- **Meshing** — chunks of 16×96×16 blocks, meshed with neighbour-aware face
  culling, per-vertex ambient occlusion and quad-flipping to keep the AO gradient
  smooth. Chunks stream in and out around the player on a per-frame time budget.
- **Lighting** — a per-column sky-occlusion term darkens caves with depth, a
  separate emissive channel carries light from glowing blocks (independent of the
  day/night cycle), and a day/night cycle drives sky colour, fog and a starfield.
- **Physics** — swept AABB collision resolved per axis with sub-stepping, plus
  jumping, sprinting, sneaking, swimming and creative flight.
- **Interaction** — Amanatides & Woo voxel raycasting for block picking, with a
  wireframe outline on the targeted block.
- **Sound** — filtered noise bursts synthesised with WebAudio for digging,
  placing, footsteps, landing and splashes.
