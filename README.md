# my-first-website.

## Cool guy doodle

A doodle of a cool guy with curly hair and sunglasses, drawn entirely in
JavaScript with the Canvas 2D API — no image assets.

- `cool-guy.js` — the drawing code (`drawCoolGuy(ctx, width, height)`)
- `cool-guy.html` — open it in a browser to see it drawn live
- `cool-guy.png` — a rendered copy
- `tools/render-cool-guy.js` — renders the PNG via headless Chromium
  (`node tools/render-cool-guy.js 1600 cool-guy.png`, needs `playwright`)
