# my-first-website.

## One Token at a Time

A 65-second motion graphics film, with an original score and sound design, about how an
AI language model writes: tokens, embeddings, attention and prediction.

▶ **[motion-graphics/how-ai-writes.mp4](motion-graphics/how-ai-writes.mp4)** (1080p, 60 fps, with sound)

Every frame is drawn in code and every sound is synthesized from scratch. See
[motion-graphics/](motion-graphics/) for how it was made and how to rebuild it.
