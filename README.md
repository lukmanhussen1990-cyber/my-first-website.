# Story Reel Kit — "100 Days Challenge" (Hindi)

A 60 s vertical (720×1280, 30 fps) flat‑2D story reel built from HTML + SVG + CSS,
recorded frame‑by‑frame with Playwright and assembled with ffmpeg.

**Final video:** `out/final.mp4` · **thumbnail:** `out/cover.png` (1080×1920) · **post caption:** `out/caption.txt`

## Build

```bash
pip install playwright numpy          # Chromium + ffmpeg must be available
cp .env.example .env                  # put ELEVENLABS_API_KEY=... in it (only needed for new voice lines)
./build.sh                            # voice → plan → music/SFX → scenes → out/final.mp4
./build.sh 6                          # re-record only scene 6, then re-assemble
./build.sh --mix                      # keep the recorded scenes, redo only the audio mix + export
```

Preview a scene live (same clock as the render): `python3 -m http.server 8000`, then open
`http://localhost:8000/scenes/scene01.html` — click to replay with the voice line.
Check single frames: `python3 render.py --stills 3 --at 0.5,2,4` → `out/stills/`.

## Layout

| Path | What it is |
|---|---|
| `script.txt` | The spoken Hindi lines, one per scene (plain Devanagari, no `**`). Subtitles use exactly this text. |
| `scenes.json` | Scene plan: hook, voice settings, gold words, voice start (`vo_at`), min length, beats, SFX cues, A/B choices. |
| `style.css`, `anim.js` | Shared look + deterministic timeline engine (all CSS animations are driven by one seekable clock). |
| `characters/` | 6 reusable SVG characters (`narrator`, `president`, `classmate1‑4`), generated by `make_characters.py`. |
| `props/` | Reusable SVG props: `desk`, `windows`, `clock`. |
| `scenes/sceneNN.html` | One HTML file per scene. |
| `fonts/` | Local Google Fonts (Tiro Devanagari Hindi, Playfair Display, Inter — SIL OFL). |
| `audio/voice/` | ElevenLabs voice lines `sceneNN.mp3`. |
| `audio/music.wav`, `audio/sfx/` | Royalty‑free bed + SFX synthesized by `sfx.py` (replace with your own files of the same name). |
| `voice.py` | ElevenLabs TTS (key from `.env`), one MP3 per line, calm pauses between sentences. |
| `render.py` | Timeline + mix plan, frame‑accurate scene recording, cover export. |
| `build.sh` | ffmpeg concat + voice/music/SFX mix (music −18 dB under the voice, SFX ducked −6 dB while the narrator speaks, final −14 LUFS) → H.264/AAC MP4. |

## Timing rule

`scene length = vo_at + voice length + 0.8 s`, never shorter than the scene's `min`
(the A/B ending uses `tail: 3.0` → at least 3 s hold after the last word), rounded to whole frames.

## Make the next reel

1. Write the new lines in `script.txt` (one per scene).
2. Update `scenes.json`: `hook`, per scene `gold` words, `vo_at`, `min`, `beats`, `sfx`, (`choices` for the A/B card).
3. Copy/adapt the scene HTML files. Building blocks:
   - characters: `<div class="char laughing" data-char="classmate2" data-expr="laugh" style="--s:.5"></div>`
     (`data-expr`: `neutral | smile | laugh`, `data-brows="serious"`, classes `idle | sway | walking | laughing`)
   - a student at a desk: `ctx.student(parent, {x, y, s, char, expr})`
   - helpers: `ctx.track(t => …)`, `ctx.count(el, from, to, t0, t1)`, `ctx.flip(el, [[t, text]…])`,
     `ctx.bounce(el, t)`, `ctx.dust(el)`, stat card markup `.stat > .label + .num`
   - CSS timing vars: `--dur`, `--vo`, and every numeric beat as `--b-NAME`
4. Delete `audio/voice/*.mp3` (and `audio/music.wav` if the length changed) and run `./build.sh`.
