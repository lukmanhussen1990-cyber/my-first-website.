# my-first-website

**Neon Rails** — a Subway-Surfers-style endless runner in a single HTML file (`index.html`).

Open `index.html` in any modern browser. No build step, no dependencies.

- Arrow keys / WASD or swipe: switch lanes, jump, roll
- Dodge trains, jump hurdles, roll under beams, ride ramps onto train roofs
- Collect coins and power-ups (magnet, 2× score, jetpack, shield)
- Procedural pseudo-3D rendering and synthesized music/SFX, all in the one file
