## Minecraft add-on: Urban Legends Horror

A Minecraft Bedrock (mobile) horror add-on is in [`urban-legends-addon/`](urban-legends-addon/).
It adds The Grinning Man, a Parasite that kills you instantly, and horror gear.
Download [`UrbanLegendsHorror.mcaddon`](urban-legends-addon/dist/UrbanLegendsHorror.mcaddon) and open it with Minecraft.
