# my-first-website.

An animated film-noir detective scene — **Murphy Law**.

The uploaded silhouette artwork is brought to life with pure HTML & CSS:
the detective's **head** and **gun hand** are separated into their own
cut-out layers that pivot on their joints (neck and shoulder), so he
tilts his head and raises his gun in a slow loop. Because the figure is
a solid black silhouette, the moving parts overlap the body seamlessly —
no visible seams or gaps.

## Files
- `index.html` — the page and layered scene
- `style.css` — layout and keyframe animations
- `assets/base.jpg` — the original artwork (static background)
- `assets/head.png` — head + hat cut-out layer
- `assets/arm.png` — gun-hand cut-out layer

## View it
Open `index.html` in any browser. Motion is disabled automatically for
visitors who prefer reduced motion.
