## Minecraft graphics add-on (Bedrock 1.21.0.26, mobile)

**Horizon Glow Graphics** — a shader-style graphics add-on (`.mcaddon`) for Minecraft Bedrock 1.21.0.26 on Android.
It is a resource pack (fog, water, sky, clouds, colour grade), **not a real shader**, and it has **not been tested on a phone yet** — see the "Read this first" box in the guide.

* Download + install guide: [`minecraft-graphics-mod/README.md`](minecraft-graphics-mod/README.md)
