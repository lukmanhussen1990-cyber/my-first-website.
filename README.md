## Blockcraft

`minecraft.html` is a Minecraft-style voxel game in a single HTML file. Open it in a browser and click **Play**.

- Endless procedural terrain: hills, mountains with snow, beaches, oceans, oak forests, flowers
- Pixel-art textures generated in code, ambient occlusion, soft tree shadows
- Day/night cycle with sunsets, stars, moon and drifting clouds
- Break, place and pick blocks; walk, sprint, swim and fly
- Touch controls on phones and tablets

The only external dependency is Three.js (r128), loaded from cdnjs.
