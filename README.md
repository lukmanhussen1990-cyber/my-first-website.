# my-first-website.

**[▶ Play Blockcraft](index.html)** — a mini Minecraft in a single HTML file.

Open `index.html` on a phone in **landscape**, or on desktop. No build step, no dependencies, no internet needed after load.

- Infinite procedural world (biomes, caves, ores, trees, water, day/night)
- Smooth per-block lighting + ambient occlusion, torches light caves
- Mine & place blocks, 2x2 + 3x3 crafting, furnace smelting, armor, tools with durability
- Health / hunger, fall & drowning damage, pigs and zombies at night
- Touch controls (stick + drag look) and keyboard/mouse, world saves to localStorage
