# my-first-website.

**Crimson Halo**: a gothic neon frame drawn entirely in code (SVG, CSS and a little JavaScript, with no image files). It has a glowing cross and halo, bat wings, chains, spiked ornaments with red gems, dripping blood, drifting smoke and floating embers.

Tap or click the circle to put your own photo inside the frame. You can also drag an image onto the page.

## Run it

Open `index.html` in a browser. There's nothing to build or install.

## Files

| File         | What it does |
|--------------|--------------|
| `index.html` | The artwork: smoke layers, the cross, halo, wings and ring (inline SVG) |
| `style.css`  | Full-screen layout at the artwork's 941 × 1672 ratio, plus the smoke drift animation |
| `script.js`  | Builds the chains, thorns, gem ornaments and blood drips, and animates embers, falling drops and the neon pulse. It also handles the photo upload. |

Animations are turned off for visitors who have set their system to reduce motion.
