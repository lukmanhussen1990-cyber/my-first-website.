## Minecraft graphics add-on (Bedrock 1.21.0.26, mobile)

**Horizon Glow Graphics** — a graphics add-on (`.mcaddon`) for Minecraft Bedrock 1.21.0.26 on Android.
It is a resource pack (fog, water, sky, clouds, colour grade) with a shader-*like* look, **not a real shader**, and it has **not been tested on a phone yet** — see the "Read this first" box in the guide.
The add-on lives on the branch `claude/minecraft-mobile-graphics-mod-kov7rd` (not merged into `main`).
