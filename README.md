# Last Mile 🎓→🏠

**One final push before freedom.**

Last Mile is a premium mobile companion for the final stretch of university: a live
exam countdown, a study planner with streaks and progress, an AI study buddy, a
"going home" journey mode with a travel checklist, a memory journal with time
capsules, and a calm-down corner for stressful nights — all wrapped in a dark,
cinematic, glassmorphism design.

Built with **Expo SDK 57 · React Native 0.86 · TypeScript · Expo Router**.

---

## Features

| Area | What you get |
|---|---|
| **Home dashboard** | Greeting, cinematic hero, live **exam countdown ring** (days · hours · minutes · seconds), **going-home countdown**, preparation level, today's missions, daily quote, feature grid, achievements strip. The dashboard changes with your journey: *preparing → exam day → exams done → home*. |
| **Study planner** | Subjects with chapters, completion %, week strip + month calendar view, daily tasks, study streak 🔥, exam schedule, past papers (PYQs) and notes per subject. |
| **AI study assistant** | Explain topics, generate MCQs (interactive quiz cards), summarise notes, create revision plans. Uses Claude through an optional secure proxy; falls back to an honest on-device **offline study buddy** (real revision-plan scheduling, extractive summaries, cloze questions from your notes). |
| **Home journey** | Travel countdown, ticket details & booking reminder, packing progress, pre-travel checklist by category (tickets, packing, documents, gifts, essentials). |
| **Memory journal** | Photos, notes and voice memories; **"Future Me" time capsules** that stay sealed for a year. |
| **Stress control** | Animated breathing coach (Box, 4-7-8, Calm) over meditation scenes, motivational quotes, sleep reminder, exam-stress tips. |
| **Premium extras** | Dark/light/system theme, local push reminders (daily motivation, study, sleep, exam & travel alerts), calendar integration, achievement badges, confetti celebration when exams are done, haptics, fully offline storage, onboarding, app icon & splash. |

## Download the Android app (APK)

A ready-to-install APK is attached to this project's delivery (see the chat), and
you can always build a fresh one:

- **GitHub Actions** — run the *Android APK* workflow (Actions tab → *Android APK* →
  *Run workflow*), or push a tag like `v1.0.0` to publish it on a GitHub Release.
- **EAS Build** — `npx eas-cli@latest build -p android --profile preview` produces an
  installable `.apk` (requires a free Expo account).
- **Locally** — see [Building an APK locally](#building-an-apk-locally).

To install: copy the `.apk` to your phone, open it, and allow *Install unknown apps*
for your browser/file manager when Android asks.

## Getting started

```bash
npm install
npx expo start          # then press a (Android), i (iOS) or w (web)
```

The app uses native modules (notifications, calendar, audio recording, image picker),
so for the full experience run a **development build**:

```bash
npx expo run:android    # or: npx expo run:ios   (or eas build --profile development)
```

### Enabling the cloud AI (optional)

Without configuration the assistant runs in **offline mode**. To use Claude:

1. Deploy the proxy in [`server/`](server/README.md) (it keeps your Anthropic API key
   on the server — never ship an API key inside an app).
2. Create `.env.local` in the project root:
   ```
   EXPO_PUBLIC_AI_PROXY_URL=https://your-proxy.example.com
   EXPO_PUBLIC_AI_APP_TOKEN=optional-shared-token
   ```
3. Restart `npx expo start`.

## Building an APK locally

Requirements: JDK 17+, Android SDK (platform 36, build-tools 36.0.0, NDK 27.1.12297006, CMake 3.22.1).

```bash
npx expo prebuild --platform android
cd android
./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a
# → android/app/build/outputs/apk/release/app-release.apk
```

The release APK is signed with the debug keystore generated by prebuild, which is fine for
sideloading. For the Play Store, build an app bundle with a real upload key
(`eas build -p android --profile production`).

## Project structure

```
src/app/           Expo Router screens (tabs: Home · Planner · Buddy · Journey · Journal)
src/components/    Design system (ui/), brand, feature components
src/theme/         Colour, typography and layout tokens + theme provider
src/store/         Zustand stores (persisted offline) + pure, tested selectors
src/services/      Notifications, calendar, media, haptics, AI (cloud + offline)
src/hooks/         Countdown, journey phase, streak, voice recording, …
src/data/          Quotes, achievements, breathing patterns, tips, sample plan
assets/            Illustrations, app icon, splash
server/            Optional Claude proxy for the AI study assistant
docs/ARCHITECTURE.md   Architecture & design contract
```

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full design system and architecture.
