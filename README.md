# my-first-website.

A little love letter website for Aman.

Open `index.html` in any browser to see it. It's a single file with no build step.

## Share it with a link

Turn on GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch**, pick the branch with `index.html` and the `/ (root)` folder, then save. After a minute the site is live at:

`https://lukmanhussen1990-cyber.github.io/my-first-website./`

## Make it yours

All the words are in `index.html`. Search for these to change them:

- `Dear Aman,` for the letter
- `Reasons I love you` for the six candy hearts and their captions
- `the one who adores you` to put your own name on the envelope
