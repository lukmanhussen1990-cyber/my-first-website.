# Three Kids reel ("Fucking romance")

Low-poly 3D animated reel (1080x1920, 30 fps, ~38.6 s): a rich 67-year-old falls for a 24-year-old, mansion, Lambo, three kids, and a CPR twist ending.

- `three-kids-reel.mp4`: final video (voiceover sped up 1.3x + synthesized SFX, no music)
- `src/scene2.js`: sets (street, restaurant, mansion, living room, bedroom), characters, 22 shots, captions, 2D effects
- `src/render.js`: Playwright frame renderer (serves on port 8766)
- `src/sfx2.py`: sound effects synthesis (numpy)
- `src/words.json`: word timings of the original voiceover
