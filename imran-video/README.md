# IMRAN — Heisenberg logo reveal

A 2-second, 1080×1080, 60 fps logo reveal: a glowing lavender character in
a Heisenberg pork-pie hat, the name **IMRAN** on a tilted 3D ring, and an
orbiting star halo. It is modelled on a reference clip (same timing, camera
moves, palette and effects) with the jester hat swapped for the pork-pie and
the text changed.

The rendered video is `out/imran-heisenberg.mp4`.

## How it works

- `assets/logo.svg` is the character artwork: the hat, head, eyes and smile
  as separate groups (see `design/CONTRACT.md`). It is generated by
  `design/build_logo.py` from the design-panel candidate in
  `design/candidates/`.
- `src/scene.js` renders every frame deterministically in headless Chromium.
  It handles the camera whip and zoom curves measured from the reference, 3D
  sway, the extruded name ring with letter flips and outline flicker, the
  star orbit, eye blink and smile sheen. It also produces true motion blur
  (averaged sub-frames), outer glow and a hot white bloom, background halo
  and grain.
- `tools/render.mjs` drives Chromium through Playwright and encodes with
  ffmpeg (H.264, yuv420p, silent AAC track, faststart).

## Render

    python3 design/build_logo.py              # only after editing the hat
    node tools/render.mjs                     # full video -> out/imran-heisenberg.mp4
    node tools/render.mjs --frames 0,40,90    # individual PNG frames -> out/frames/
    node tools/render.mjs --text NAME         # a different name

This needs Node with Playwright/Chromium and `ffmpeg` on `PATH`.
`tools/preview-logo.mjs` previews logo art on its own. `tools/compare.py`
puts rendered frames side by side with reference frames.
