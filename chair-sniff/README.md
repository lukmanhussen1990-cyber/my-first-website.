# Chair Sniff: 9:16 3D comedy short (Blender + bpy + ffmpeg)

`final.mp4` is 1080x1920, 30 fps, H.264 + AAC. Its length follows the voiceover (40.0 s). The captions are burned in.

Everything is generated by scripts: characters, the office, the animation, the cameras, the render and the captions. The same commands re-render the video after you change the voiceover.

## What's in this folder

| File | What it is |
|---|---|
| `final.mp4` | The finished short |
| `chair_sniff.blend` | The full Blender scene: 33 shots, one camera per shot bound to timeline markers. Sketchfab-model textures are packed. Poly Haven and MakeHuman textures load from `assets/`: run `scripts/fetch_assets.py assets` once, or the full pipeline. |
| `captions/captions.ass` | Captions (Poppins ExtraBold, 1–3 words, hard cut on/off) |
| `voiceover.mp3` | Your voiceover, the only audio track |
| `script.txt` | Narration, one line per shot group, used to time the shots and caption punctuation |
| `assets_manifest.json` | Every third-party asset with its source, author and licence |
| `credits.txt` | Credits for the CC-BY assets (not shown in the video) |
| `scripts/` | Pipeline (below) |
| `make_video.sh` | Runs the whole pipeline |

## Pipeline

1. `scripts/transcribe.py`: faster-whisper (local, `medium.en`) produces word timestamps → `build/words.json`.
2. `scripts/make_timing.py`: aligns `script.txt` to those words and writes:
   - `build/timing.json`: start and end of each narration line. All 33 shots are placed as fractions of these lines.
   - `captions/captions.ass`: 1–3 word chunks (max 15 characters), each shown exactly when its first word is spoken.
3. `scripts/build_characters.py`: MakeHuman characters via the MPFB2 add-on (CC0 output) with a Mixamo-named skeleton. They are the main guy, the crush, the boss and 3 coworkers.
4. `scripts/build_scene.py`: the office set, props, actors, poses, cameras and visibility → `chair_sniff.blend`. Poses come from `scripts/poses.py` and are applied by `scripts/rigpose.py`.
5. `scripts/render.py`: EEVEE, 1080x1920, 2 samples per pixel, AgX base (medium) contrast, soft sun shadows, fast GI/AO, no depth of field, no bloom.
6. `scripts/encode.sh`: ffmpeg burns in the captions and muxes `voiceover.mp3` → `final.mp4`.

## Re-render with a new voiceover

```bash
scripts/setup.sh                      # once: venv with bpy 5.2 + faster-whisper, installs MPFB2
cp /path/to/new_voiceover.mp3 voiceover.mp3
# edit script.txt if the words changed (keep one line per shot group, 14 lines)
STEPS="transcribe timing scene render encode" ./make_video.sh
```

- First run on a new machine: run `./make_video.sh` with no `STEPS`. That also downloads the assets (`assets/`) and builds the characters.
- Shot timing follows the new voice automatically. Every shot is defined as a fraction of its narration line, and the "Genius!" cut snaps to that word.
- If you only want new captions, run `STEPS="transcribe timing encode"`. This reuses the rendered frames in `build/frames`.
- Render speed: about 7 s per frame on a 4-core CPU with no GPU (software OpenGL), so about 2.3 hours for the film. With a GPU it takes a few minutes.
  - `SAMPLES=8` gives smoother anti-aliasing.
  - `JOBS=2` starts a second render process that shares the frames. It only helps if you have spare CPU cores.
  - Rendering resumes where it stopped: existing frames in `build/frames` are skipped.
- To tweak a shot, open `chair_sniff.blend` in Blender 5.2+. Each shot's camera is bound to the timeline marker of the same name. Re-run `STEPS="render encode"` afterwards, or edit `scripts/build_scene.py` and rebuild.

## Assets and licences

- **Characters:** MakeHuman system assets (CC0) through MPFB2. The main guy wears the MakeHuman white tee, jeans and black shoes, like the reference.
- **Office, textures, HDRI, cushions, desk props:** Poly Haven (CC0).
- **Office chairs** (mesh chair, gas-lift chair, rolling chairs), **perfume, gel pad, monitors, desktop PC, whiteboard, water cooler:** Sketchfab models under CC-BY 4.0, downloaded through the public Objaverse mirror of Sketchfab. They are credited in `credits.txt`.
- **Font:** Poppins ExtraBold (SIL OFL), in `fonts/`.
- **Animation:** keyframed body poses (stiff, Mixamo-style, no facial acting) on the MPFB2 *Mixamo* skeleton. Mixamo downloads need an Adobe login, which this automated build can't use. Because the bones are already named `mixamorig:*`, Mixamo FBX clips can be dropped onto the same rigs later.
