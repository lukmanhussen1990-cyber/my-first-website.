    How to play

    1. You start with a rock.
    2. Type something that beats it — e.g. paper.
    3. Now you need something that beats paper. Keep the chain going!
    4. If the judge says your answer doesn't win, or you repeat something you already used, it's game over.

    Tip: bigger, stronger, and cleverer things usually win. Classic matchups (water vs fire, garlic vs vampire…) are known to the judge.

    Settings

    The game works fully offline with a built-in judge. For a smarter, more creative judge, you can optionally use Claude with your own Anthropic API key. The key is stored only in this browser and sent only to api.anthropic.com.
