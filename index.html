Substitution + By Parts
Linking two integrals through integration by parts
If A = ∫π0 cos x(x+2)2 dx, then ∫π/20 sin 2xx+1 dx is equal to

  1. Rescale so the sine loses its factor of 2. Put x = y/2, so dx = dy/2, and the limits 0 → π/2 become 0 → π. I = ∫π/20 sin 2xx+1 dx
  2. Simplify the new integrand. Now sin 2x = sin y and x+1 = y+22, so the two factors of 2 cancel exactly. I = ∫π0 sin yy+2 dy
  3. Integrate by parts with u = 1y+2 and dv = sin y dy, giving v = −cos y. I = [ −cos yy+2 ]0π − ∫π0 cos y(y+2)2 dy
  4. Evaluate the boundary term. With cos π = −1 and cos 0 = 1: [−cos yy+2]0π = 1π+2 + 12
  5. Recognise the leftover integral. The remaining piece is precisely A — the dummy variable name makes no difference. I = 12 + 1π+2 − A
Answer Option (1)  12 + 1π+2 − A

Monotonicity of an Integral Function
Comparing an accumulation function with ln x
f(x) = ∫x1 ett dt, x ∈ R+. Then the complete set of values of x for which f(x) ≤ ln x is

  1. Read off the two facts the integral gives you. The limits coincide at x = 1, and the Fundamental Theorem supplies the derivative. f(1) = 0,   f′(x) = exx
  2. Compare by building a difference function. Set g(x) = f(x) − ln x on R+. g′(x) = exx − 1x = ex − 1x
  3. Fix the sign of the derivative. For every x > 0 we have ex > 1, so numerator and denominator are both positive — g is strictly increasing on all of R+. g′(x) > 0  ∀ x ∈ R+
  4. Anchor it at the one point you know. g(1) = f(1) − ln 1 = 0 − 0 = 0. A strictly increasing function crosses zero exactly once, at x = 1. g(x) ≤ 0 ⟺ x ≤ 1   and   g(x) > 0 ⟺ x > 1
  5. Intersect with the domain. Only x > 0 is allowed, so the solution set is half-open at 0 and includes the equality point x = 1. f(x) ≤ ln x  ⟺  x ∈ (0, 1]
AnswerOption (1)  (0, 1]

The Reciprocal Substitution
Two improper integrals that secretly agree
Let I1 = ∫∞0 x2√x(1+x)6 dx, I2 = ∫∞0 x√x(1+x)6 dx. Then

  1. Write the powers as exponents. The two integrands differ only in the numerator exponent, 5/2 versus 3/2. I1 = ∫∞0x5/2(1+x)6 dx,   I2 = ∫∞0x3/2(1+x)6 dx
  2. Apply the reciprocal substitution to I1. Put x = 1/t, so dx = −dt/t2. The limits flip from 0 → ∞ to ∞ → 0, and that flip absorbs the minus sign. I1 = ∫0∞ t−5/2(1 + 1t)6 (− 1t2) dt
  3. Clear the compound denominator. Since (1 + 1/t)6 = (1+t)6/t6, that t6 climbs into the numerator. t−5/2 · t6 · t−2 = t6 − 2 − 5/2 = t3/2
  4. Read off the result. What is left is exactly the integrand of I2, with t as a dummy variable. I1 = ∫∞0t√t(1+t)6 dt = I2
  5. Cross-check with the Beta integral. Using ∫∞0 xm−1(1+x)m+n dx = B(m, n), the exponents give I1 = B(7/2, 5/2) and I2 = B(5/2, 7/2). Beta is symmetric, so they match. B(7/2, 5/2) = B(5/2, 7/2) ⟹ I1 = I2
AnswerOption (4)  I1 = I2

Lagrange Mean Value Theorem
Bounding an integral you cannot evaluate
If f(x) = ∫x2 dt1+t4, then

  1. Differentiate the accumulation function. The lower limit is the constant 2, so f(2) = 0. f′(x) = 11+x4
  2. Apply the Mean Value Theorem on [2, 3]. f is continuous and differentiable there, so some c ∈ (2, 3) satisfies: f(3) − f(2)3 − 2 = f′(c) ⟹ f(3) = 11+c4
  3. Bound the unknown point. From 2 < c < 3, raising to the fourth power preserves the inequalities: 16 < c4 < 81 ⟹ 17 < 1 + c4 < 82
  4. Invert — which flips the inequality. Taking reciprocals of positive quantities reverses the order. 182 < f(3) < 117
  5. Match against the options. The upper bound is strict, so f(3) < 1/17 — which also rules out options (2), (3) and (4) at once. f(3) < 117 ≈ 0.0588
AnswerOption (1)  f(3) < 1/17

Integrating an Inverse Function
Turning f−1 into something you can actually integrate
If f(x) = x + sin x, then ∫2ππ f−1(x) dx is equal to

  1. Confirm the inverse exists, and find the matching limits. f′(x) = 1 + cos x ≥ 0, so f is increasing and invertible; and since sin π = sin 2π = 0: f(π) = π,   f(2π) = 2π
  2. Substitute x = f(t). Then dx = f′(t) dt and f−1(x) = t. By the step above, t also runs from π to 2π. I = ∫2ππ t · f′(t) dt
  3. Integrate by parts — this is the whole point of the substitution, since it trades f′ for f. I = [t f(t)]π2π − ∫2ππ f(t) dt
  4. Evaluate the boundary term. Using f(2π) = 2π and f(π) = π: [t f(t)]π2π = 2π · 2π − π · π = 4π2 − π2 = 3π2
  5. Evaluate the ordinary integral of f. With cos 2π = 1 and cos π = −1: ∫2ππ(t + sin t) dt = [t22 − cos t]π2π = (2π2 − 1) − (π22 + 1) = 3π22 − 2
  6. Subtract. The two minus signs on the constant combine into a plus. I = 3π2 − (3π22 − 2) = 3π22 + 2 ≈ 16.80
AnswerOption (2)  3π22 + 2
