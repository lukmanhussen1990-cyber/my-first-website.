# Custom sounds

Every sound plays a custom `ih.*` id **and** a vanilla id, so the pack is audible
straight away. Drop your own Ogg Vorbis files here with these names to replace
them: `build1`, `build2`, `house_done`, `zap`, `horde_start`, `horde_wave1`,
`horde_wave2`, `horde_end`, `zombie_spawn`, `zombie_bomb`, `menu`.

Format: Ogg Vorbis, 44.1 kHz, keep them short.
