# The World's Longest Subway: a vertical 3D reel, made with code

A 53-second Instagram Reel (1080x1920, 9:16, 30 fps). It is a cake-slice cutaway diorama of the
Great Wall at golden hour. Machines dig a subway under the whole wall. John rides it from start
to finish and arrives very old.

**Final video:** `out/great_wall_subway_reel.mp4` (H.264 High, yuv420p, AAC 192 kb/s 48 kHz)

Everything is generated by code. That includes the 3D scene, the textures, the music, the sound
effects and the subtitles. The only exception is the text-to-speech for the voices.

| | |
|---|---|
| 3D | Three.js r180 (PBR materials, PCF soft shadows, GTAO ambient occlusion, sky IBL, bloom, ACES filmic, grade + vignette, SMAA + 4x MSAA). Rendered frame by frame in Chromium with software WebGL (Mesa llvmpipe through a virtual X display). Every frame is a pure function of time, so there is no screen recording and no dropped frames. |
| Textures | `tools/make_textures.py` (numpy): bricks with cracks and chips, stone blocks, rock with cracks and mineral grit, soil with pebbles, grass, concrete, machine grime/scratch/chip masks, station tiles, particle sprites |
| Voices | `script.json` + `tools/make_voices.py` (ElevenLabs with word timestamps, or local Kokoro TTS + faster-whisper word alignment) |
| Sound | `tools/make_audio.py`: synthesised score and 27 synthesised sound effects, ducked under the voice, loudness -14 LUFS / -1 dBTP |
| Subtitles | `tools/make_subtitles.py`: one word at a time, burned in with libass |

## Files

```
script.json              the voiceover script (exact subtitle spelling) + voice settings
timeline.json            the single source of timing: scenes, voice windows, sound-effect cues
voices/                  one WAV per line + timings.json (word timestamps)
scene/                   the Three.js scene (index.html, main.js, world/, props/, anim/, fx/, tex/)
tools/render_frames.mjs  renders PNG frames with headless Chromium
tools/place_voices.py    fits each voice line into its scene window
tools/make_subtitles.py  word-by-word ASS subtitles
tools/make_audio.py      music + effects + mix
tools/export.py          plate + mix + subtitles -> final MP4
rebuild_with_elevenlabs.sh   one command: new ElevenLabs voices -> new video (no 3D re-render)
rebuild_audio.sh             same, but keeps the current voice files
out/plate.mp4            the clean 3D render (no subtitles, no audio): used for re-exports
out/stems/               voice / music / sfx stems of the last mix
```

## Swapping in the ElevenLabs voices later (no 3D re-render)

The voices in this version are **local Kokoro TTS**. When the video was made, ElevenLabs could not
be used. No `ELEVENLABS_API_KEY` was set, and the connected ElevenLabs account had 0 credits with
its free tier disabled. The pipeline is ready for ElevenLabs as soon as a key with credits exists:

```bash
cd reel
ELEVENLABS_API_KEY=sk_your_key ./rebuild_with_elevenlabs.sh
# or put ELEVENLABS_API_KEY=sk_your_key in reel/.env and run ./rebuild_with_elevenlabs.sh
```

That single command does the following:
1. Makes all 7 lines with ElevenLabs using the `/with-timestamps` endpoint, so word timings come
   straight from ElevenLabs. It writes `voices/*.wav` and `voices/timings.json`.
2. Fits each line into its scene window (`timeline.json` → `voice_windows`). A line that would
   overrun is sped up by at most 15%. John's line always starts on its cue.
3. Rebuilds the word-by-word subtitles with the new timing.
4. Rebuilds the music and effects mix. The music still cuts out right before John's line,
   whenever that line now starts.
5. Re-exports `out/great_wall_subway_reel.mp4` from `out/plate.mp4`. The 3D is not re-rendered.

`./rebuild_with_elevenlabs.sh auto` falls back to the local voices if ElevenLabs fails.

**Voices configured in `script.json`:**
- Narrator: **Elena Wren** (`N2MNNfQ4izkc8hqG3xMa`), friendly, warm, neutral accent. Model
  `eleven_multilingual_v2`, speed 1.08.
- John (very old): **The Lesser Poet** (`RZbjJyfi4xuKalm0NLb5`), a real 81-year-old voice. Low
  stability for a shaky delivery, speed 0.8.
- Both are ElevenLabs *library* voices. If your account cannot use them directly, add them to
  "My Voices" in ElevenLabs first, or change the `voice_id`. Each voice also has a premade
  `fallback_voice_id` (George for the narrator, Bill for John), which is tried automatically if the
  library voice is refused.
- To use other voices, edit `voice_id` / `model_id` / `voice_settings` in `script.json`.

The script text in `script.json` is the exact spelling used for the subtitles.

Note: John's mouth movement in the 3D render follows the timing of the current local voice. A new
voice changes the audio and subtitles but not the rendered mouth. To re-sync the mouth, re-render
frames 1470–1590 (scene 7) after making the new voices.

## Rebuilding from scratch

```bash
cd reel
npm install                                   # three + playwright (uses the system Chromium)
pip install numpy scipy soundfile pillow kokoro-onnx faster-whisper
python3 tools/make_textures.py                # procedural textures -> scene/tex/
python3 tools/make_voices.py                  # voices (auto: ElevenLabs if a key works, else local)
xvfb-run -a -s "-screen 0 1280x2000x24" node tools/render_frames.mjs --out frames --workers 2   # 1590 frames, ~1-2 h on 4 CPU cores
ffmpeg -framerate 30 -i frames/f%05d.png -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p out/plate.mp4
./rebuild_audio.sh                            # placement, subtitles, mix, final export
```

Without `xvfb-run` the renderer falls back to SwiftShader, which is about 4x slower. Handy render options: `--frames 3.5s,12s` renders single stills, `--w 540 --h 960` renders at half
size, and `--q "noao=1&noblur=1"` gives a fast preview. Open `scene/index.html` through
`node tools/server.mjs` to look around.

## The story (7 scenes, about 7 s each)

1. Wide shot of the wall at sunset. The excavator rolls in, digs two bucketfuls into a dump truck,
   and a stone tunnel portal pops up.
2. The bucket hits solid granite with a clang. A tunnel-boring machine snaps together and chews
   through the rock. The bulldozer pushes rubble out to a dump truck.
3. The raw tunnel crumbles. Concrete rings thunk into place ring after ring, and the lamps turn on.
4. A small train tries the steep path that follows the wall and slides back down. Glowing dots show
   the gentle deep path, and the boring machine and the excavator dig it.
5. The camera pulls back along the wall to the horizon. A snack car, a sleeping car and a cinema
   car drop in and couple up. The bulldozer smooths the last bit of track bed.
6. The subway glows at dusk. The machines salute with their headlights. The train shoots into the
   tunnel, and John waves from the window with his popcorn.
7. The last station. The doors open and John steps out, now very old with a knee-length beard and
   a walking stick. The music stops: "Is this... my stop?"
