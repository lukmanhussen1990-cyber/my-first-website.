# Assets to make outside of code

Everything in `previews/look-test-v1.jpg` is 100% code. These assets upgrade it closer to the reference
(photo-like faces and fur). If an asset never arrives, the code version stays in.

Every prompt ends with the same style line: **low-poly 3D video game style like a PS2 game, slightly pixelated textures**

## A. Faces (biggest upgrade) — wrapped onto the front of the 3D heads

the frame edge to edge with ears cut off (the 3D heads have their own ears). Tip: make the first image of each cat,
then use ChatGPT's edit ("same image, only change …") for its variants so they match exactly.

## Sounds (real recordings; code can't fake these well)
Any format (mp3 / wav / m4a). Royalty-free (e.g. Pixabay) or your own cat.

| File | What | Used in |
|---|---|---|
| `meow_hook` | one clear, friendly adult meow (~1 s) | Part 1 "MEOW!" |
| `meow_long` | long, loud, demanding meow (~1.5–2 s) | Part 8 food bowl |
| `meow_chirp` | short, sweet chirp / trill, "mrrp?" (~0.5 s) | Part 8 door |
| `meow_soft` | soft, polite meow (~0.7 s) | Parts 5, 7, 9 |
| `kitten_mew` | 2–3 tiny kitten mews (~2 s) | Part 2 |
| `hiss` | cat hiss (~1 s) | Part 4 |
| `purr` | calm purring (~4 s) | Part 10 |
| `kibble` | dry cat food poured into a bowl (~2 s) | Part 5 |
| `door_open` | front door opening (optional) | Part 8 |
| `music` | soft, cute background track, 70 s+ (optional) | whole video |

Made in code: pops (every chip/bubble), whooshes (transitions), sparkle/ding, and — if no `music` arrives — a simple soft plucky loop.
