# Giant Spider Hunter — Minecraft Bedrock add-on

A small spider watches you from the trees. Once its eyes are on you, it grows into a giant
whose body rises above the forest canopy and whose legs span several trees — and it hunts you.

Built for **Minecraft Bedrock Beta 1.21.0.26** (Android). Entity id: `horror:giant_spider`.

> This README is completed at the end of the build with final validation results.
