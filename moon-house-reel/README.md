# John's Moon House — a 3D vertical Reel made entirely with code

John digs a house into the Moon. Each problem gets a real-science fix, and it ends with a twist.

| | |
|---|---|
| **Final video** | `output/moon_house_reel.mp4`: 1080×1920 (9:16), 30 fps, 55 s, H.264 High + AAC 48 kHz, −14 LUFS |
| 3D render only | `output/moon_house_clean.mp4`: no subtitles, no audio. Re-exports reuse it, so the 3D is never re-rendered |
| Voice lines | `voice/line_01.wav` … `voice/line_07.wav` (one file per line) + `voice/timings.json` (word timings) |
| Script | `script/script.json` (lines + scene numbers) and `script/voiceover.txt` (plain text) |
| QA stills | `output/qa/scene_1.png` … `scene_7.png`: one full-resolution frame per scene |

## Swap in the ElevenLabs voice later (one command)

```bash
cd moon-house-reel
cp .env.example .env          # put your key in it:  ELEVENLABS_API_KEY=sk_...
./remake_voice.sh
```

That's all. The script:
1. Generates all 7 lines with ElevenLabs. It uses the `/with-timestamps` endpoint, so every word gets an exact start and end time. The lines are saved as `voice/line_XX.wav`, replacing the local voice.
2. Re-places the lines on the timeline. Each line starts at its scene, and the "So …" half is anchored to the moment the fix appears on screen, so a voice with different pacing still lines up with the animation.
3. Re-mixes the music and sound effects under the new voice (with ducking).
4. Re-times the word-by-word subtitles.
5. Re-exports `output/moon_house_reel.mp4` from the existing 3D render. Nothing is re-rendered, and it takes about a minute.

Options:

```bash
./remake_voice.sh --voice-id <voice id> --model eleven_multilingual_v2 --speed 1.05
./remake_voice.sh --from-files ~/Downloads/moon_voice   # line_01.mp3 … line_07.mp3 made in the ElevenLabs app (no API key needed)
```

- The default voice is "Holden – Warm Midwest Narrator" (`oXpouBLuKFVTJwcJO3YL`), a warm voice with a hint of dry humour. It's a Voice Library voice, so add it to *My Voices* first. If the account can't use it, the script falls back to the premade voices Eric and then Brian.
- With `--from-files`, word timings are measured from the audio with a local aligner (faster-whisper, corrected against exact TTS timings: about 0.06 s average error). The subtitle text always comes from the script, so the spelling never changes.

**About the voice in this version:** ElevenLabs was attempted first, through the ElevenLabs connector, because no `ELEVENLABS_API_KEY` or `.env` file was present. The account returned *"0 credits remaining"* and *"Free Tier access has been disabled"*. As instructed, the video was finished with a local voice instead: Piper TTS `en_US-ryan-high`, slightly sped up. Its word timings are exact, taken from Piper's own phoneme alignment.

## How it's made

- **3D:** three.js r170, rendered **frame by frame** (1,650 frames) in headless Chromium with software WebGL (SwiftShader). There is no screen recording. Every frame is a pure function of time, so motion is perfectly smooth and frames can render in parallel. See `scene/js/*.js`.
- **Look:**
  - Physically based materials. All textures are generated by code:
    - moon dust with micro-craters and pebbles
    - the layered cut-away rock with faceted stones and cracks
    - the Earth with oceans, land and clouds
    - suit fabric, boot prints with tread, wood, panels and icons
  - Hard sunlight with a 4096² shadow map and very dark shadows, plus a dim Earth-shine fill so John stays readable.
  - Baked ambient occlusion in craters, bloom, ACES filmic tone mapping, a vignette, 4× MSAA and a static dither against banding.
- **Diorama:** the ground is a "cake slice" floating in a black sky full of stars, with the blue Earth glowing in the sky. Cavities (the hole, the room, the airlock, the light pipe) are cut into the cross-section by a shader.
- **Physics:** dust, rocks and sparks fly on ballistic arcs at lunar gravity (1.62 m/s²). There are no puffy dust clouds, because there's no air. Dotted trails show the slow arcs.
- **Characters and animation:**
  - John is a rigged toy-like figure: leg IK, blinking, eyelids, brows, several mouths.
  - The digging machine and the house parts snap in with a spring bounce. Camera moves are smooth splines.
  - Heat shows as an orange glow, cold as a blue glow, air as soft white dots.
- **Science beats:**
  1. A hole is "sort of" a house.
  2. Low gravity makes dust fly too far, so a slow machine digs instead.
  3. Moon dust is sharp and sticky, so the suit gets seals and the door gets a dust brush.
  4. The surface swings between hot and cold, but a few metres down the temperature is steady.
  5. There's no air, so an airlock and oxygen tanks go in.
  6. Space rocks fall, so a thick regolith layer covers the roof.
  7. Twist: no phone signal.
- **Sound:** everything is synthesised in `audio/synth.py`:
  - calm D-lydian space music that **stops dead** on the "no signal" pop-up
  - helmet breathing, shovel scrapes, the machine hum, seal clicks, the airlock hiss, the air filling the room, a happy breath, rock thuds, dust pouring, the phone pop-up and more
  - the mix in `audio/mix.py` uses voice ducking, −14 LUFS and a −1 dBTP limiter
- **Subtitles:** `subs/make_ass.py` writes one word at a time in Fredoka Bold: white, with a thick black outline and a soft shadow. Each word pops in with a tiny bounce. They sit 36 % from the top, away from the bottom 20 % and the right edge, and are burned in with libass. Shots were framed so faces and key action stay out of the subtitle band.

## Rebuild everything from scratch

Needs Node 18+, Python 3.10+, ffmpeg with libass, and Playwright's Chromium (`npm i -g playwright && npx playwright install chromium`).

```bash
./render_all.sh       # local voice -> render 1,650 frames (about 1.5–2 h on 4 cores) -> final video
./make_video.sh       # just re-export (voice placement + mix + subtitles + encode)
node render/render.js --scale 0.5 --out build/qa --stills 3,9,17,25,34,42,52   # quick preview stills
```

Folder map:

- `scene/`: three.js scene (`timeline.json` has the scene times and "So …" cue times that the voice is anchored to)
- `render/`: frame renderer and QA contact sheets
- `audio/`: voice (Piper / ElevenLabs), cue sheet, synth, mix
- `subs/`: subtitles
- `assets/fonts/`: Fredoka (OFL)
