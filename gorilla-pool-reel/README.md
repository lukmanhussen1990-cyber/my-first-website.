# Gorilla Pool — vertical Instagram Reel (made with code)

A 50-second, 1080×1920, 30 fps 3D animated Reel. A kid hires a grumpy, cartoony gorilla to dig a backyard pool.
Each problem gets a fix, and it ends with a cannonball twist.

**Final video:** `output/gorilla_pool_reel.mp4` (H.264 High at about 12 Mb/s, AAC 192 kb/s 48 kHz stereo, 1080×1920, 30 fps, 50.0 s, −14 LUFS)

Everything is generated by code:

| Part | How |
|---|---|
| 3D | Three.js (WebGL2), rendered frame by frame in headless Chromium (no screen recording). Every frame is computed from its time value alone, so the render is deterministic. |
| Look | Procedural PBR materials (soil strata with pebbles, stones and roots; striped lawn; concrete; blue tiles with caustics; wood; stucco), shell-rendered gorilla fur, 30 000 instanced swaying grass blades, soft PCF shadows, GTAO ambient occlusion, image-based sky light, bloom, ACES filmic tone mapping, colour grade, vignette, 4× MSAA |
| Sound | Music and every sound effect are synthesized in Python (`tools/build_audio.py`). The music stops dead on the cannonball splash. |
| Voice | ElevenLabs when available; otherwise local Kokoro-82M TTS (see below) |
| Subtitles | Word by word, timed to the voice, burned in with libass (`tools/make_subtitles.py`) |

## Swapping in the ElevenLabs voice later (no 3D re-render)

```bash
cd gorilla-pool-reel
export ELEVENLABS_API_KEY=sk_your_key        # or put ELEVENLABS_API_KEY=... in gorilla-pool-reel/.env
./rebuild_with_elevenlabs.sh                  # optional: --voice <voice_id>
```

This takes a minute or two. It:

1. Generates the 6 lines with ElevenLabs. It uses the `/with-timestamps` API, so word timings are exact, and passes the neighbouring lines as context so the delivery flows.
2. Places each line on its story beat. Lines are cut before "So …" so the fix part lands on the fix in the animation. If a voice is slower, the second half moves earlier, and if it is still too long the line is sped up slightly, pitch preserved.
3. Rebuilds the mix (music ducks under the voice), regenerates the subtitles from the new timing, and re-exports `output/gorilla_pool_reel.mp4` from the stored clean render `output/video_clean.mp4`.

The current voice is backed up to `voice/previous/` first. If the API call fails, nothing is changed.

If ElevenLabs answers *"Free Tier access has been disabled"*, the account needs a paid plan (or a key from an account that is not flagged). That is what happened when this video was made, so the local voice was used.
The default ElevenLabs voice is set in `script/voiceover.json` (`elevenlabs.voice_id`, currently *Holden – Warm Midwest Narrator*: relaxed, friendly, a little dry humour). Model and voice settings are in the same file.

## Files

```
script/voiceover.json      narration text + where each line sits on the timeline (+ ElevenLabs settings)
script/voiceover.txt       the same script as plain text
voice/line01..06.wav       the narrator lines (one file per line) + voice/timings.json (word times)
output/gorilla_pool_reel.mp4   the Reel
output/video_clean.mp4     the 3D picture only (no subtitles, no audio), used for re-exports
output/subtitles.ass       burned-in subtitles; output/word_times.json = absolute word timings
output/audio/              voice / music / sfx stems and the final mix
render/scene/*.js          the Three.js scene: world.js (yard, soil, pool, water), characters.js,
                           props.js, fx.js (particles), timeline.js (all animation + camera), beats.js (story timing)
render/render.mjs          headless renderer (stills or video segments)
render/render_all.sh       full parallel render -> output/video_clean.mp4
tools/                     tts_local.py, tts_elevenlabs.py, align_words.py, build_audio.py,
                           make_subtitles.py, export_video.py
rebuild_with_elevenlabs.sh new voice + re-export, no 3D render
make_all.sh                the whole pipeline from scratch
```

## Requirements

* ffmpeg built with libass (`ffmpeg -filters | grep ass`)
* Python 3 with `numpy scipy soundfile pillow`. The local voice also needs `kokoro-onnx` and
  `faster-whisper` (for word timing from the audio). The ElevenLabs path needs neither.
* For a 3D re-render only: Node 18+ and Playwright's Chromium (`cd render && npm install`)

Useful render commands:

```bash
cd render
node render.mjs stills --times 3.6,17.9,43.5 --w 540 --h 960 --out ../output/stills   # quick checks
node render.mjs stills --times 28.9 --q "cam=1.1,2.1,2.0,1.1,1.95,-3.25,30"            # close-up camera override
node tools/shotcheck.mjs      # checks that faces / key action stay clear of the subtitle band
WORKERS=3 ./render_all.sh     # all 1500 frames: about 4 hours on a 4-core CPU with no GPU (SwiftShader)
```
