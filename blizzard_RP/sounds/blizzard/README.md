# Custom blizzard sounds

Every sound plays a custom `sw.*` id **and** a vanilla id, so the pack is audible
straight away. Drop your own Ogg Vorbis files in here with the exact names below
and they layer on top.

| File name (add `.ogg`) | Played when                          |
| ---------------------- | ------------------------------------ |
| `wind1`, `wind2`       | howling wind while you are exposed    |
| `storm_start`          | a blizzard begins, and the 1 min warning |
| `storm_end`            | the storm passes                      |
| `freezing1`, `freezing2` | your body heat hits zero            |
| `heartbeat`            | spare id for a slow heartbeat loop    |
| `cocoa`                | drinking Hot Cocoa                    |
| `hand_warmer`          | using the Hand Warmer                 |
| `weather_stone`        | the Weather Stone flips the weather   |
| `menu`                 | the menu opens                        |

Format: Ogg Vorbis, 44.1 kHz. Keep `wind1`/`wind2` short and loopable.
